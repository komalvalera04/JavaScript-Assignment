Error message: SyntaxError: "undefined" is not valid JSON

Explanation:

This error occurs because JSON.parse() expects a valid JSON string, but the code passes undefined: JSON.parse(undefined);

How to fix it:

Pass valid JSON to JSON.parse(), or check that the value exists before parsing.
For example:

function fetchUser() {
const userData = '{"name":"Rahul"}';
return JSON.parse(userData);
}
Now JSON.parse() receives valid JSON and can convert it into a JavaScript object.
